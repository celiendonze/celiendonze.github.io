# Agent Instructions

## Development Flow
- Open `index.html` in a browser to view the project.
- The primary interaction is clicking the image to toggle between `kdo_ferme.jpg` (closed gift) and `kdo_ouvert.png` (opened gift).

## Files
- `index.html`: The main entry point.
- `style.css`: Contains the styling for the page.
- `script.js`: Contains the logic for the image toggle functionality.
